## 客户端候选验证

HTTP/WS 共用真实登录与设备关联头；诊断配置从宿主读取；初始化失败与正常退出有生命周期记录；Angular 接收和应用阶段附真实消息 ID、安全整数序号，IPC 接受精确正整数文本。身份由宿主提供，未增加身份时序标签。

- 本地路径依赖的候选诊断构建通过，Rust 诊断相关 24 项测试通过。
- 定向前端 3 套 22 项测试、应用 TypeScript 检查、包边界检查和 lint 通过。
- `cses-message:build` 停在未改动的 `ccc-core-common`：context 入口的 rootDir 不能包含主包源码，报 TS6059。本轮未修改该依赖。
- 全量 Jest 出现任务边界和表格等未改动模块失败，按验证扩张停止规则终止，不报告全仓绿色；本轮定向证据独立保留。

## 正式启用的剩余条件

1. 客户端现有四个依赖锁定公共 crates.io 的 0.1.9，默认 feature 未包含业务诊断。新 API 不能靠只开配置进入旧二进制。0.1.10 发布计划检查通过，四包目标版本未占用；[待启用补丁](正式客户端启用待发布.patch)已通过 `git apply --unidiff-zero --check`。该补丁准备同时更新依赖和默认 feature，发布成功后才应用并重新生成正式 lock。
2. 公共包发布是不可逆源码上传；本轮此前明确授权的发布对象为 Grafana，已经单独请求公共 crates.io 发布授权。当前没有执行上传、版本 tag 或 push。
3. 发布后必须用正式 registry 依赖重新验证并构建客户端，解决或独立处理上述既有前端构建阻塞。候选路径依赖通过不能替代正式构建通过。
4. Go PRE 必须部署已验证的新源码，并在正式 YAML 启用持续诊断。Promtail 现有运行集群规则还需合入实际 Helm/GitOps 真源；不能把一次运行集群修改当作永久配置。
5. 最后核对实际客户端登录、群清单、在线接收、离线恢复及页面应用，再记录用户交互证据。当前 CLI 不替代 Tauri/WebView 页面验收。

普通技术指标没有用户标签；选择用户时不回退全局值。用户、群聊、登录和设备明细在 JSON 正文中筛选。服务端全受众送达率与永久丢失结论仍需完整权威分母，不能用本机三十秒保存窗口替代。
