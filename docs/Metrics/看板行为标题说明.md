# 看板行为标题说明

当前看板：[登录与群聊：消息接收、保存和补齐情况](http://192.168.6.66:30300/d/helix-client-channel-v1)。

2026-09-07 发布第 2 版，98 个区域和面板全部采用中文行为描述。指标名、查询表达式与证据口径放在面板说明中。

| 用户要判断的问题 | 看板标题 |
|---|---|
| 登录之后没有群或群少了 | 登录后群聊是否完整 |
| 断网期间的消息有没有恢复 | 重新登录或恢复连接后，消息是否补齐 |
| 消息停在接收、保存还是应用阶段 | 收到的消息走到了哪一步 |
| 哪些序号缺失、后续是否恢复 | 哪些消息序号不连续，后来是否补齐 |
| 各群最新保存进度 | 每个群的消息已保存到哪个序号 |
| 用户点击后的等待时间 | 点击操作后是否及时完成 |
| 后台处理过慢 | 后台任务是否排队积压 |

默认身份留空查看全局；选择用户或群聊后按准确标识筛选。没有身份标签的运行指标不能充当用户指标。

本次标题发布不等于新增业务埋点已经部署。各生产者的接线和真实样本以实施验证记录为准。第 2 版回读的所有标题和查询一致，见 [发布证据](看板行为标题发布验证-2026-09-07.json)。

静态检查同时禁止面板标题包含英文字母或下划线；查询检查通过查询语义定位面板，不再依赖技术标题。
