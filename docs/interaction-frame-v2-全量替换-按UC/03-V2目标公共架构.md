# V2 目标公共架构

> 本文范围排除 G03/G03a，不得将上传链路混入本次 Frame V2 清退。

目标单向依赖为：

`ActionBinding/HostObservation -> ActionInvocationEnvelope -> Tick -> Effect -> Go authority -> PersistAtomic -> PersistOk -> SurfaceComposer -> InteractionFrameV2 -> V2 codec -> SurfaceRuntime -> adapter -> component -> UiDirective -> FrameApplied/ActionReceipt`。

Helix domain 拥有业务决策；application 负责 Tick/Effect 编排；infrastructure 实现 HTTP/WS/SQLite；接口层只转换协议。Angular 不拥有消息排序、权限、未读和回执计算。

迁移缺口包括统一 25 Gate writer、`surfaceEpoch` 进入 slot state 并校验、生产 `FrameApplied` 回传、V2-only reader、Frame 版本/旁路计数和删除后回归。

## 硬切不变量

全链验收开始前必须同时满足：

1. Helix 目标 Gate 的运行时只允许调用 V2 builder/emitter，任何 V1 producer 命中立即失败。
2. cses-client 生产 codec 只接受 `schemaVersion=2`，V1 不得 normalize、fallback 或继续渲染。
3. `v1Frames` 与 `rawBusinessFallbacks` 是可执行计数器，不是从日志文本推断。
4. 旧 V1 类型与测试代码可以暂存到验收通过后再物理删除，但不得有生产可达路径。

所以“V2 主路径 + V1 fallback”不是候选状态，也不能进入 E2E。
