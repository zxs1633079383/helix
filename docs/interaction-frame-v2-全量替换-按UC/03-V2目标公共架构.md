`ActionBinding/HostObservation -> ActionInvocationEnvelope -> Tick -> Effect -> Go authority -> PersistAtomic -> PersistOk -> SurfaceComposer -> InteractionFrameV2 -> V2 codec -> SurfaceRuntime -> adapter -> component -> UiDirective -> FrameApplied/ActionReceipt`。
