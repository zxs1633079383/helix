# 跨仓版本固定与验收

> 本文范围排除 G03/G03a，不得将上传链路混入本次 Frame V2 清退。

## 固定面

Helix revision、cses-client Cargo manifest/lock pin、Strict Matrix source revision/raw hash/semantic hash、Helix fixture manifest、client fixture manifest 必须来自同一 immutable candidate。当前这些面不一致，状态为已阻塞。

## 唯一迁移顺序

1. 客户端 V2 reader 正向测试通过。
2. 客户端 V2 reader 负向测试通过。
3. Helix 25 Gate 全量 V2 writer 完成。
4. 逐 Gate replay/Persist barrier 完成。
5. Strict Matrix 和 fixture 重新生成。
6. revision、Cargo pin、合同 pin、fixture hash 一致。
7. 一个 Native candidate、双用户连续执行全部 Gate。
8. required fail=0、required skip=0。
9. v1Frames=0。
10. rawBusinessFallbacks=0。
11. 生产 reader 禁收 V1。
12. 删除 V1 兼容代码。
13. 删除后重新构建。
14. 删除后最终聚合回归。
15. 最终仍为 25/25 才能完成。

不得按 UC 单独重复编译 Native；一次 candidate 只进行一次完整构建和连续聚合执行。
