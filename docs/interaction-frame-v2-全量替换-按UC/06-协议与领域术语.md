# 协议与领域术语

> 本文范围排除 G03/G03a，不得将上传链路混入本次 Frame V2 清退。

| 术语 | 中文定义 |
|---|---|
| `ActionBinding` | Helix 投影在完整 VM 中的可执行语义能力 |
| `ActionInvocationEnvelope` | 客户端回传 opaque `actionRef`、输入、观察 revision 与 epoch 的调用信封 |
| `InteractionActionReceipt` | 调用受理/拒绝/等待 Frame 的回执，不是业务完成证明 |
| `InteractionFrameV2` | 包含 runtime、typed Surface mutations 与 directives 的原子事务 |
| `SurfaceScope` | user、channel、thread 或 receipt 的稳定作用域 |
| `surfaceEpoch` | attach/session generation，阻止旧会话 mutation 写入新 slot |
| `revision/baseRevision` | Surface snapshot/patch 的原子版本关系 |
| `causationId` | action/observation 与最终 mutation 的相关键 |
| `UiDirective` | Frame 提交后执行的 reveal、focus、clear 或 detach 语义 |
| `FrameApplied` | Angular 整帧提交后的确认 |
| `PersistAtomic/PersistOk` | 本地事实提交屏障；durable Frame 不得越过失败屏障 |

未定义的“ActionFrame”不得继续使用，必须拆解成上述正式类型。Go WS envelope `seq`、业务 `channel_event.event_seq`、同步 cursor 与 Surface revision 是四个不同序列。
