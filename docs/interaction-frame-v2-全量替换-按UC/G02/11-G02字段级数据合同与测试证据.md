## 1. Canonical inbound

| Gate | command | required | optional | unknown |
|---|---|---|---|---|
| `G-02` | `im_send_message` | `channel_id`、`type`、`props` | `text`、`replied`、`req_id` | 拒绝 |

canonical payload 使用 snake_case，且仅允许表中字段。camelCase 只可存在于公共 facade
intent；PC 与 Mobile 必须委托 Helix 共享 normalization，不能各写一套字段转换。

## 2. HTTP、WS 与远端权威

| Gate | HTTP request | HTTP response | WS/sync inbound |
|---|---|---|---|
| `G-02` | `POST /api/cses/posts/create`，`type=DOCUMENT`；canonical message/simpleMessage=`"【文档】 http://doc-pre.cses7.com/doc/6a6036184de8e1a30ef73c15"`，`props.document={version:1,url:"http://doc-pre.cses7.com/doc/6a6036184de8e1a30ef73c15",title:"打开文档",placeholder:true}`；这是文档消息卡片，不是文件附件或上传任务 | HTTP 200 application/json；CommonRes.status=SUCCESS；完整 message/data 必须入证据包，并与 Helix 投影及远端事实对账 | `post` |

observer 必须依赖自身 WS/sync/恢复链，不能读取 actor 的 intent。

## 3. InteractionFrameV2

完整 envelope 必须包含：

`schemaVersion=2, transactionId, causationId?, runtime{connection,initialSync,recovery},
mutations[], directives[]`。

每个 mutation 必须包含：

`surface, scope, revision, baseRevision?, surfaceEpoch, causationId?, mutation`。

| Gate | canonical Surface | schema |
|---|---|---|
| `G-02` | `message.timeline` | `InteractionFrame/v2` |

本 GN 的 typed 接受值：

`MessageContentVm::Document{documentId,title,summary,access}`；`DeliveryVm` 只允许 sending/sent/failed

业务不变量：

`type=DOCUMENT` 且 `props.document` 必须由 Helix 解析为 typed document；PC/Mobile 不读取 raw props 兜底

## 5. 负向合同

- 文档卡片字段不得由 UI 猜测
- 文档链接消息不得进入 media upload prepare/put/complete 状态机
- schemaVersion 非 2、未知字段、重复 slot、scope/surface 不匹配、patch 缺 baseRevision
  均必须 fail closed。
- PC/Mobile 不得从 raw WS、HTTP、SQLite row 或 command receipt 重建 typed VM。
