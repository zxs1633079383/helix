## 1. Canonical inbound

| Gate | command | required | optional | unknown |
|---|---|---|---|---|
| `G-13` | `im_channels_view` | `channels` | 无 | 拒绝 |

canonical payload 使用 snake_case，且仅允许表中字段。camelCase 只可存在于公共 facade
intent；PC 与 Mobile 必须委托 Helix 共享 normalization，不能各写一套字段转换。

## 2. HTTP、WS 与远端权威

| Gate | HTTP request | HTTP response | WS/sync inbound |
|---|---|---|---|
| `G-13` | `POST /api/cses/channels/view` body `{channels:[{id,isRoot}]}` | HTTP 200 application/json；CommonRes.status=SUCCESS 只表示 view command 受理，未读终态必须等待定向 `update_channel` 的 member 绝对态在本地提交并发布 paired Frame | `update_channel` 携带当前 viewer 的 `unreadCount`, `mentionCount`, `urgentCount`, `lastReadSeq` 等 `channel_member` 绝对态；它与 HTTP reply 独立竞态 |

HTTP 200/accepted 不是 Frame 终态。写路径必须等待 matching PersistOk 或权威 readback；
observer 必须依赖自身 WS/sync/恢复链，不能读取 actor 的 intent。

## 3. InteractionFrameV2

完整 envelope 必须包含：

`schemaVersion=2, transactionId, causationId?, runtime{connection,initialSync,recovery},
mutations[], directives[]`。

每个 mutation 必须包含：

`surface, scope, revision, baseRevision?, surfaceEpoch, causationId?, mutation`。

| Gate | canonical Surface | schema |
|---|---|---|
| `G-13` | `message.left-dialog-list` | `InteractionFrame/v2` |
| `G-13` | `message.unread-summary` | `InteractionFrame/v2` |

本 GN 的 typed 接受值：

`DialogListVm` 对应行 badges 清零并与 `UnreadSummaryVm` 在同一 Frame 原子更新；read completion 必须绑定 viewer/channel authority

业务不变量：

HTTP SUCCESS 不建立完成；未读清零不在 UI 先写；客户端不得提交 userId/unreadCount 冒充服务端权威

## 4. Frame inventory

1. `channel-view-command`
2. `http-accepted-only`
3. `update-channel-member-authority`
4. `channel-member-persist`
5. `paired-dialog-unread-frame`

上述是阶段 inventory，不代表每一阶段都必然独立出 Frame。Fixture producer 必须从真实
`Tick/PortReply/Inbound -> ImModule::handle -> Effect::Emit` 捕获 actual Frame，再固定
允许的部分顺序、可选 Frame 和终态。

## 5. 负向合同

- 未读清零不得由 UI 先行写入
- schemaVersion 非 2、未知字段、重复 slot、scope/surface 不匹配、patch 缺 baseRevision
  均必须 fail closed。
- PC/Mobile 不得从 raw WS、HTTP、SQLite row 或 command receipt 重建 typed VM。
