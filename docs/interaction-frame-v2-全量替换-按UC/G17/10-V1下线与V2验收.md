# G17 V1 下线与 V2 验收

## Gate 前置

G17 当前没有 exact Gate，因此下面所有条目均为拟议验收合同，不能勾选或 promote。首先必须解决：

```text
CONTRACT_DRIFT:
Document G17 has no exact Gate, render kind, required props, allowed action,
or evidence slot. Canonical G-17 is already reserved for channel pinning.
```

## 合同验收

- [ ] Strict Matrix 已登记一个不与 canonical `G-17` 冲突的 exact Gate
- [ ] render kind、required props、allowed action 已冻结
- [ ] G17 明确为 observation-driven，无伪造 ActionBinding
- [ ] schema 1 reader 拒绝 row delta
- [ ] schema 2 reader exact decode row delta
- [ ] upsert 新行缺完整 row 时 fail-closed
- [ ] remove 与同 row 其他操作冲突时 fail-closed
- [ ] move anchor 缺失或跨 section 时 fail-closed
- [ ] baseRevision gap 触发 snapshot
- [ ] surfaceEpoch mismatch 触发重新 attach
- [ ] window token mismatch 触发 snapshot

## 投影与原子性验收

- [ ] dialog + unread 任一 slot 失败时均不提交
- [ ] `FrameApplied` 只在所有 slot swap 后发出
- [ ] pinned/normal/closed 跨 section 正确
- [ ] 插入当前窗口后正确挤出边界 row
- [ ] off-window 变化不扰动当前 DOM
- [ ] 未变化 row identity 保持稳定
- [ ] refresh/late-entry snapshot 与连续 delta 最终 VM 一致
- [ ] duplicate transaction 幂等

## 性能验收

- [ ] 在线单行变化不触发 `im_query_dialog_list` 全量 scan
- [ ] 单行 Frame 不再携带全部 normal/closed rows
- [ ] wire payload 随 operation 数 `k` 增长，而不是总行数 `n`
- [ ] 100、500、2000 行基准分别记录 Helix build、encode、transport、Angular stage 和 DOM 时间
- [ ] 最坏 move 成本单独报告，不用平均值掩盖
- [ ] snapshot/resync 的 `O(n)` 成本与频率单独报告

## 多视角与证据

- [ ] actor viewer 收到其个性化 row delta
- [ ] observer viewer 收到权限和未读不同的 row delta
- [ ] 退出成员收到 remove/closed 的正确 viewer 结果
- [ ] late-entry 只靠 snapshot 得到相同终态
- [ ] refresh replay 得到相同终态
- [ ] durable evidence 同时覆盖 Go、SQLite、Helix Frame、Tauri ingress、Angular apply 与 DOM

当前没有同一 candidate 的完整证据，全部保持未勾选。
