# 移动端 25 Gate 严格矩阵

| Gate | Mobile 用户入口 | Helix 输入 | Command | 当前 QuickJS binding | Surface | 目标移动 UI |
|---|---|---|---|---|---|---|
| GS01 | 连接建立与 `hello` | `HostObservation` | `im_query_dialog_list` | `im.sync.dialogList` | `message.left-dialog-list`、`message.unread-summary` | 连接完成后，会话列表与未读摘要一次出现；连接受理不能显示为空列表成功 |
| GS02 | `sync notify` 入站 | `Inbound` | `im_sync_channels` | `im.sync.channels` | `message.left-dialog-list`、`message.unread-summary`、`message.timeline` | 恢复期间保留最后一致视图，提交后会话、未读和受影响时间线同帧更新 |
| GS03 | `pong.gaps` | `Inbound` + `Timer` | `im_sync_channels` | `im.sync.channels` | `message.left-dialog-list`、`message.unread-summary`、`message.timeline` | 补偿期间显示同步状态但不清空旧视图；合法补偿提交后只刷新受影响 Surface |
| GS04 | 选择频道或未知 `channelId` | `HostObservation` | `im_channel_load_increment_by_channel_id` | `im.channels.ensureLoaded` | `message.channel-summary`、`message.composer`、`message.timeline` | 未知频道加载成功后频道头、输入区和时间线同时可用；失败时保留原频道 |
| G01 | 输入文本并提交 | `ActionBinding(message.create)` | `im_send_message` | `im.send` | `message.composer`、`message.timeline`、`message.left-dialog-list`、`message.unread-summary` | 同一消息行从 sending 收敛为 sent 或 failed，禁止 JS 再造第二条临时消息 |
| G02 | 选择文档内容并提交 | `ActionBinding(message.create)` | `im_send_message` | `im.send` | `message.composer`、`message.timeline` | 文档消息显示文档卡片、发送状态和失败后的输入恢复，不由 JS 解读 document props |
| G04 | 撤回操作或 type-3 同步事实 | `ActionBinding(revoke)` / `Inbound` | `im_revoke` | `im.posts.revoke` | `message.timeline`、`message.thread-detail`、`message.left-dialog-list` | 发送者撤回后时间线、线程和会话摘要同步显示撤回态，原操作按钮失效 |
| G04a | 撤回操作或 type-3 同步事实 | `ActionBinding(revoke)` / `Inbound` | `im_revoke` | `im.posts.revoke` | `message.timeline`、`message.thread-detail`、`message.left-dialog-list` | 观察者从同步事实得到撤回态与 cursor 提交，不执行主动撤回 HTTP |
| G05 | 选择目标并提交转发 | `ActionBinding(forward)` | `im_relay_messages` | `im.posts.relayMessages` | `message.timeline`、`message.left-dialog-list`、`message.composer` | 每个目标频道独立呈现转发终态，源频道与失败目标不被假成功覆盖 |
| G06 | 点击 emoji 或快捷回复 | `ActionBinding(react)` | `im_quick_reply` | `im.posts.quickReply` | `message.timeline`、`message.thread-detail` | emoji 聚合数量、当前 actor 选中态和线程详情一致；拒绝时恢复旧聚合 |
| G07 | 发起加急或点击确认 | `ActionBinding(urgent/urgent_confirm)` | `im_urgent_post` / `im_urgent_confirm` | `im.posts.urgentPost`、`im.posts.urgentConfirm` | `message.timeline`、`message.participant-receipts`、`message.unread-summary` | 加急标识、确认人数、目标列表与按钮权限一致，actor/observer 视图按权限分离 |
| G08 | 选择时间并提交 | `ActionBinding(schedule_create)` | `im_create_schedule` | `im.posts.createSchedule` | `message.channel-summary`、`message.left-dialog-list`、`message.timeline` | 定时消息提交中、已创建和失败状态可恢复，observer 不显示 owner 草稿 |
| G09 | 确认取消 | `ActionBinding(schedule_cancel)` | `im_cancel_schedule` | `im.posts.cancelSchedule` | `message.channel-summary`、`message.left-dialog-list` | 取消成功后定时入口消失，重复取消幂等，失败时保留可重试状态 |
| G10 | attach 频道或上拉 | `HostObservation` / `ActionBinding(load_older)` | `im_query_messages_by_channel` / `im_load_older_context` | `im.posts.queryMessagesByChannel`、`im.posts.loadOlderContext` | `message.timeline` | 首屏显示有界时间线；上拉追加旧消息且保持滚动锚点，Partial/Miss 显式回源 |
| G10a | attach 频道或上拉 | `HostObservation` / `ActionBinding(load_older)` | `im_query_messages_by_channel` / `im_load_older_context` | `im.posts.queryMessagesByChannel`、`im.posts.loadOlderContext` | `message.timeline` | 围绕锚点补齐 before context，整窗提交后保持锚点位置，失败不破坏当前窗口 |
| G11 | 请求定位 `postId` | `ActionBinding(locate)` | `im_get_posts` | `im.posts.locate` | `message.timeline` | 目标窗口提交后执行 RevealMessage，目标不存在或失败时不移动当前滚动位置 |
| G12 | 打开线程、分支或提交回复 | `ActionBinding(open_reply_tree/reply)` | `im_get_replies` / `im_get_reply_branch` | `im.posts.getReplies`、`im.posts.getReplyBranch` | `message.thread-detail`、`message.timeline` | 线程 root/replies 图完整出现；回复发送终态与主时间线一致，不由 JS 拼 reply tree |
| G13 | 频道可见或点击已读 | `ActionBinding(channel_read)` / `HostObservation` | `im_channels_view` | `im.posts.readChannel` | `message.left-dialog-list`、`message.unread-summary`、`message.timeline` | 会话未读数、频道已读边界和时间线读态同帧变化，重复可见观察幂等 |
| G14 | 单条可见、打开回执或点击已收到 | `ActionBinding(post_read/template_received)` / `HostObservation` | `im_post_read` / `im_template_received` | `im.posts.markRead`、`im.posts.templateReceived` | `message.participant-receipts`、`message.timeline`、`message.thread-detail` | 读者列表、当前消息读态和线程详情一致；HostObservation 不直接伪造已读成功 |
| G14a | 单条可见、打开回执或点击已收到 | `ActionBinding(post_read/template_received)` / `HostObservation` | `im_post_read` / `im_template_received` | `im.posts.markRead`、`im.posts.templateReceived` | `message.participant-receipts`、`message.timeline`、`message.thread-detail` | 模板已收到状态只在权威提交后出现，重复确认幂等，失败保留按钮 |
| G15 | 提交话题或群聊创建表单 | `ActionBinding(make_topic/create_channel)` | `im_make_topic` / `im_create_channel` | `im.channels.makeTopic`、`im.channels.create` | `message.topic-list`、`message.channel-summary`、`message.left-dialog-list`、`message.member-roster` | 新话题在 topic list、频道摘要、会话列表和成员表中原子出现 |
| G15a | 提交话题或群聊创建表单 | `ActionBinding(make_topic/create_channel)` | `im_make_topic` / `im_create_channel` | `im.channels.makeTopic`、`im.channels.create` | `message.topic-list`、`message.channel-summary`、`message.left-dialog-list`、`message.member-roster` | 新群聊在首批四个 Surface 原子出现，成员与 viewer 隔离由权威事实决定 |
| G16 | 关闭、退出或保存设置 | `ActionBinding(close/leave/settings)` | `im_channel_close` / `im_channel_leave` / `im_channel_change_info` | `im.channels.close`、`im.channels.leave`、`im.channels.changeInfo` | `message.channel-summary`、`message.left-dialog-list`、`message.composer`、`message.member-roster` | 关闭后输入区禁用、频道从列表移除或标记关闭，其他频道保持可用 |
| G16b | 关闭、退出或保存设置 | `ActionBinding(close/leave/settings)` | `im_channel_close` / `im_channel_leave` / `im_channel_change_info` | `im.channels.close`、`im.channels.leave`、`im.channels.changeInfo` | `message.channel-summary`、`message.left-dialog-list`、`message.composer`、`message.member-roster` | 退出后成员表、频道可见性和输入权限一致；observer 看到成员变化 |
| G16c | 关闭、退出或保存设置 | `ActionBinding(close/leave/settings)` | `im_channel_close` / `im_channel_leave` / `im_channel_change_info` | `im.channels.close`、`im.channels.leave`、`im.channels.changeInfo` | `message.channel-summary`、`message.left-dialog-list`、`message.composer`、`message.member-roster` | 设置保存后频道头、会话行和成员相关权限按 expectedVersion 原子更新 |

机器范围：25/25；`G03/G03a`：0。Mobile binding 只证明静态调用面存在，不证明 HTTP、WS、
Persist、Frame 或 UI 完成。
