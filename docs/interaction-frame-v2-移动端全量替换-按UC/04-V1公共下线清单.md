# V1 公共下线清单

## 首轮 E2E 前切断生产可达路径

- Helix 所有目标 Gate 的 InteractionFrame V1 writer/builder/emitter。
- Mobile production reader 对 schema 1 的接收、normalize 与 raw business fallback。
- Venus JS 由 `im:post:*`、`im:channel:*` 等 raw event 重建 UI 的生产路径。
- `im.store.snapshot/applyPatch/drainPatches` 对已迁移 Surface 的生产可达路径。

此阶段允许 V1 源文件暂存，但运行命中必须 fail-closed 并可计数；首轮证据要求
`v1Frames=0`、`rawBusinessFallbacks=0`。

## 首轮纯 V2 通过后物理删除

- V1 writer/reader/type/codec/fixture/compat test。
- Mobile `SurfaceRuntime::kLegacyInteractionFrameSchemaVersion` 与 schema 1 decode。
- `MobileImSdk::applyEventProjection` 中已迁移业务事件分支。
- Venus 页面 temporary/server identity reconcile、排序、未读、权限与 reply-tree reducer。

`schemaVersion` 字段保留并强制等于 2。producer 与 consumer 必须在同一 candidate 切断，任一端
仍有 V1 production reachability 都不得进入首轮纯 V2。`ActionInvocationEnvelope/v1`、
`InteractionProtocol/v1`、Strict Matrix 文件版本与 V1 Frame 不是同一版本域，不在删除范围。
