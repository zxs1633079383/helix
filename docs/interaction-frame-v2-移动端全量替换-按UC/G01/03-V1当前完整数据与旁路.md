# G01 V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.send` |
| C++ command | `im_send_message` |
| Helix Effect | `storage_upsert`、`http_write`、`timer`、`projection` |
| HTTP | `POST /api/cses/posts/create` body `{viewers,message,mentions,temporaryId,type,simpleMessage,channelId,userId,teamId,userSnapshot,id,props,topicId,revoke,createAt,replyId?,replyRootId?,replyFirstLevelId?}`；`replied={id,reply_id,reply_root_id,reply_first_level_id}` 只在 Helix 组装回复三锚，`req_id` 只透传 `Cses-Track-Id`，两者均不作为 HTTP body 字段 |
| WS | 正常发送主推 `post`；`update_channel` 不是普通发送主链路单独推送，仅在读标记/频道变更/撤回最后一条/加急等副链出现；错误本地 `im:post:send-failed` |
| PG | `post`、`channel`、`channel_member`、`channel_event` |
| SQLite | `message`、`pending_send` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

生产旁路是 raw `im:*` event、`MobileImSdk::applyEventProjection`、`im.store.*` 或页面本地
reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
