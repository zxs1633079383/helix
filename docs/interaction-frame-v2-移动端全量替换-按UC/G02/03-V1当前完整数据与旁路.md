# G02 V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.send` |
| C++ command | `im_send_message` |
| Helix Effect | `upload`、`storage_upsert`、`http_write`、`projection` |
| HTTP | `POST /api/cses/posts/create`，同上，`type=DOCUMENT`；占位字段建议 `message/simpleMessage="【文档】 http://doc.cses7.com/doc/abc123"`，`props.document={version:1,url:"http://doc.cses7.com/doc/abc123",title:"打开文档",placeholder:true}`；后续替换为 message-v3 的 `props.document={snapshot,version:1}` |
| WS | `post` |
| PG | `post`、`channel`、`channel_member`、`channel_event` |
| SQLite | `message`、`pending_send` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
