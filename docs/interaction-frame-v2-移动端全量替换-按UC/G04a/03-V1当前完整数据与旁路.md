|---|---|
| QuickJS | `im.posts.revoke` |
| C++ command | `im_revoke` |
| Helix Effect | `http_write`、`storage_upsert`、`projection`、`sync_request` |
| HTTP | 无 UI 主动 HTTP；由 `channels/load/increment` / `sync/notify` 拉到事件 |

demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
