# G05 V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.posts.relayMessages` |
| C++ command | `im_relay_messages` |
| Helix Effect | `storage_read`、`http_write`、`projection` |
| HTTP | `POST /api/cses/posts/createPosts` body `{posts:[Post...],channelIds:[...]}` |
| WS | `post` per target channel |
| PG | `post`、`channel`、`channel_member`、`channel_event` |
| SQLite | `message`、`channel` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
