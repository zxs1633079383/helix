# G12 V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.posts.getReplies`、`im.posts.getReplyBranch` |
| C++ command | `im_get_replies` / `im_get_reply_branch` |
| Helix Effect | `http_read`、`projection` |
| HTTP | `POST /api/cses/posts/getReplies` body `{replyId,pageNumber,pageSize,revoke?}`；`POST /api/cses/posts/getReplyBranch` body `{replyFirstLevelId,pageNumber,pageSize,revoke?}` |
| WS | 无直接 WS |
| PG | `post` |
| SQLite | `message`、`reply_tree` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

生产旁路是 raw `im:*` event、`MobileImSdk::applyEventProjection`、`im.store.*` 或页面本地
reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
