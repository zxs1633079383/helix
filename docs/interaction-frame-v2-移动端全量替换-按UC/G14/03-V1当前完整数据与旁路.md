# G14 V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.posts.markRead`、`im.posts.templateReceived` |
| C++ command | `im_post_read` / `im_template_received` |
| Helix Effect | `http_write`、`storage_upsert`、`projection` |
| HTTP | `POST /api/cses/post/read` body `{channelId,posts:[postId]}` |
| WS | `post_read` |
| PG | `post`、`channel_member`、`channel_event` |
| SQLite | `message_receipt` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
