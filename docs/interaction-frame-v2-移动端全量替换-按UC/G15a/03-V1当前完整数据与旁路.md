# G15a V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.channels.makeTopic`、`im.channels.create` |
| C++ command | `im_make_topic` / `im_create_channel` |
| Helix Effect | `http_write`、`storage_upsert`、`projection` |
| HTTP | `POST /api/cses/channel/create` body `{type,userIds,displayName,forceCreate}`；session 身份、team、成员角色与默认 `pictureType=USER/picture.userIds` 由服务端派生，客户端不得提交 team/role/owner/picture |
| WS | `channel_created` |
| PG | `channel`、`channel_member`、`channel_members_snapshot`、`channel_event`、`post` |
| SQLite | `channel`、`channel_member` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

生产旁路是 raw `im:*` event、`MobileImSdk::applyEventProjection`、`im.store.*` 或页面本地
reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
