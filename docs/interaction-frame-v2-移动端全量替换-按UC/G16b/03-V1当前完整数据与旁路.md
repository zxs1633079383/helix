# G16b V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.channels.close`、`im.channels.leave`、`im.channels.changeInfo` |
| C++ command | `im_channel_close` / `im_channel_leave` / `im_channel_change_info` |
| Helix Effect | `http_write`、`storage_upsert`、`projection`、`transport_broadcast` |
| HTTP | `POST /api/cses/channel/member/leave` body `{channelId,userId?,newCreator?}` |
| WS | `channel_member_update`, `quit_company`（公司域也可能推） |
| PG | `channel_member`、`channel`、`channel_event`、`post` |
| SQLite | `channel_member` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

生产旁路是 raw `im:*` event、`MobileImSdk::applyEventProjection`、`im.store.*` 或页面本地
reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
