# GS01 V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.sync.dialogList` |
| C++ command | `im_query_dialog_list` |
| Helix Effect | `local_scan`、`projection` |
| HTTP | `POST /api/cses/channels/load/increment` body `{timestamp,cursors:[{channelId,fromSeq}]}`；单频道 `POST /api/cses/channel/load/incrementByChannelId` body `{channelId}` |
| WS | `hello` 建立连接；零个或多个 `increment_channel.data` 承载频道快照，服务端水位读取成功时包含 `lastEventSeq`，根群 cursor 对账时包含 `needSync`；同一连接最后收到 `increment_channel_end` 只证明该批 WS 入队结束，不证明本地持久化或最终投影完成 |
| PG | `channel`、`channel_member`、`channel_event`、`post` |
| SQLite | `channel`、`channel_member`、`channel_event_cursor` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

生产旁路是 raw `im:*` event、`MobileImSdk::applyEventProjection`、`im.store.*` 或页面本地
reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
