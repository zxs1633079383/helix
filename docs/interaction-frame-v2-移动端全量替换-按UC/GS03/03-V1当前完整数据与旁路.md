# GS03 V1 当前数据与旁路

| 层 | 当前事实 |
|---|---|
| QuickJS | `im.sync.channels` |
| C++ command | `im_sync_channels` |
| Helix Effect | `sync_request`、`projection` |
| HTTP | `POST /api/cses/channel/sync/notify` body `{cursors:[{channelId,fromSeq}]}` |
| WS | `pong.data` 固定包含 `text=pong`，对账时可含 `gaps:[{channelId,fromSeq,maxSeq}]` 与 `hashMismatch`；普通 pong 可只有 `text`。随后触发的 HTTP `/channel/sync/notify` 本身不产生业务 WS；并发 `post` / `posts_update` / `increment_channel_end` 不得替代补偿 HTTP、本地持久化或最终投影 |
| PG | `channel_event`、`post`、`channel` |
| SQLite | `channel_event_cursor`、`message` |
| 当前 UI | raw batch 经 listener/legacy reducer 后由 JS/C++ 重建 |

生产旁路是 raw `im:*` event、`MobileImSdk::applyEventProjection`、`im.store.*` 或页面本地
reconcile。该 Gate 的确切产品页面源码未包含在当前 Mobile 仓：`SOURCE_MISSING`；只能证明
demo/test/adapter 调用面，不能宣称真实移动 UI 已验收。
