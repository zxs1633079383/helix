# 空JSON消息链修复验证记录

## 合同与实现
- 成员 last_post 精确空串按空字符串摘要投影，不以 post 重建权威摘要、计数或 revision；非空非法JSON显式报错。viewer校验、读回和Persist屏障保留。
- update_channel.lastPost 空串继续普通PATCH；对象/字符串编码对象保持原路径，损坏JSON/错误类型拒绝，null仍按稀疏PATCH忽略。
- expediteMap 精确空串与Go合法null统一表示无加急数据，即时/缓冲编辑保留正文更新与已有加急字段；对象仍走原加急路径，错误类型在gate前拒绝。
- 加急类型检查直接借用wire值，不新增序列化后再次解析或成员全量扫描。
- 无schema迁移：空lastPost本身是合同允许的无摘要事实，不能全表替换为虚构消息对象。
