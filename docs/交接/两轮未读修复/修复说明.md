## 行为

Increment 的 count/anchor/readSeq/revision 同组按严格递增版本落库。零未读显式清空，旧版本/重复版本/无版本帧不能覆盖已落库的新版本成员态。Sync 读回使用当前 viewer 成员投影覆盖频道缓存，公开成员列表仅保留原有身份字段。

旧协议兼容通过通用附加等值守卫限制为 projection_revision=0；SQLite 与 Web session store 都执行同一守卫，Core 不引入运行时或业务依赖。
