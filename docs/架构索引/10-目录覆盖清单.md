## 1. 覆盖规则

- `模块图`：crate 或工程模块级类图 + 流程/状态图。
- `目录图`：每个生产源码文件夹至少一张类图 + 一张中文流程/状态图。
- 辅助目录不冒充运行时业务，但必须有角色、验证流和阅读入口。
- `target/`、`worktrees/`、`.git/`、`.idea/`、`smoke/build/` 等生成/工作目录不纳入。

## 6. Mermaid 校验约定

文档中的每个 `mermaid` fenced block 都是独立、可直接作为 `.mmd` 输入的源码。校验时应逐块提取，分别交给 Mermaid CLI 解析；不能只检查 fence 是否闭合。

最低校验项：

1. Mermaid CLI 对每一块返回 0。
2. 所有 `stateDiagram-v2` 迁移标签和 flowchart 边标签均为中文。
3. Markdown 相对链接目标存在。
4. 当前生产源码目录集合与本清单集合一致。
