## ✅ 已拍板结论（七条 · 各文档须与此一致）

> 来源：[评审纪要](./helix-技术评审纪要.md)。这是消除文档漂移的单一事实源。

1. **cursor 归属**：cursor 是 IM 概念，归 `helix-im`，**不进 core**；core 只有通用 spec 原语。
2. **栅栏升级**：core 零业务概念用 `cargo public-api` **冻结公开类型面**（allowlist），非 grep 禁词。
3. **四能力解耦 = 行为级**（模块只 emit 它需要的 Effect），**非编译级裁剪**；`Effect` 是单一 enum。唯一未来口子：wasm 包体积。
4. **重试归 driver**，helix-im 不重试、失败只标 UnSend（源码 `ports/http.rs` 注释为准）。
5. **DomainEvent 契约必须版本化**，否则换成「事件 schema 对不齐地狱」。
6. **现状两端在跑**（桌面 Tauri/Angular + 移动 Flutter），浏览器在路上（非「三端已在跑」）。
7. **driver 方法体当前全是 `todo!()`**：流程图/序列图是「编译期类型验证为真的契约意图」，运行时待 M2。

**头号技术风险（主动上桌）**：乱序增量同步（断线重连 backfill）未验证 → **M1 第一优先级：先写 backfill 的 proptest，再写 driver**。
