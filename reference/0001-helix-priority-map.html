Reference 0001

Helix 学习优先级速查

先学判断边界，再学代码细节。Rust 语法跟着 Helix 的真实接口学，不先背一整本。

P0

指令与北极星

先读 docs/GOAL.md、docs/ROADMAP.md §二 P0、docs/harness/OPERATING.md、根 AGENTS.md。目标是知道什么不能偏离、现在卡在哪、该调什么验证。

P1

Core 心智模型

helix-core 只定义 ports、module host、tick、effect、error，不做 I/O、不认 IM、不依赖运行时。关键词：Module、Tick、Effect、Storage、Transport、EventSink。

P2

Host Driver 共享泵

helix-driver-host 是 native 与 FFI 共同的执行泵和 I/O 兑现层。重点看 run_engine_loop、EngineDeps、BatchSink、RecordingSink、StorageOp、rows codec、HTTP envelope、BoundedSpawner。

P3

IM 业务模块

helix-im 是第一个业务模块。先按目录职责读：acl、channel、send、sync、query、todo、outbound、ws。命令体看真抓包文档，投影看 projection schema。

P4

端 Driver 分工

driver-native 是 PC/Tauri 壳；driver-ffi 是 C ABI + C++ shim host 壳。两者都不该复制 core 或 IM 业务，只装配 host pump、ports、事件出口与生命周期。

P5

边界坑卡

按 HX-C 卡学反例：core 零运行时、Send 边界、features additive、热路径 O(1)、FFI 不 unwind、批量过边界、测试可证伪、观测逐跳完整。

P6

Rust 语法补点

按代码需求补：trait/generic bound、enum + pattern match、Result 错误、owned vs borrow、cfg/features、async channel 边界、unsafe extern C、raw pointer ownership。
